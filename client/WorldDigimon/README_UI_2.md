# WorldDigimon UI 2.2.0

Interfaz para el cliente WoW 3.3.5a. El servidor sigue siendo la autoridad: el addon solo presenta estado, envía órdenes protegidas y mantiene preferencias visuales.

Incluye barra de combate separada de las barras nativas, paneles de colección, técnicas, rutas y misiones, escala adaptable, posiciones arrastrables, configuración y texturas locales Power-of-Two en TGA.

La vista `routes` muestra nivel, afinidad, victorias y núcleo evolutivo devueltos por `WDMMO V2`. Las formas descubiertas se restauran sin volver a pagar requisitos.

La felicidad persistente y los efectos temporales de comida llegan desde el servidor y se muestran en la tarjeta del compañero. El ajuste `Datos de cuidado` oculta o muestra empatía, felicidad y efectos sin cambiar el estado del Digimon.

Comandos: `/digimon`, `/digimon luchar`, `/digimon salir`, `/digimon config`, `/digimon reset`.

La previsualización entregada es estática; debe verificarse dentro del cliente antes de publicar cambios visuales definitivos.
